Manga Bookmarker

Your library is stored in a private GitHub repository that you own. Create the repo and a token once, paste them here, and every bookmark is saved straight into it.

A fine-grained token with access to only the data repo and the permission Contents: Read and write. It stays in this browser and is only sent to api.github.com.

Adds “Open in library” links to the popup and the badge on manga sites, and lets the website’s “Add by hand” form fill itself in from a link.

The extension needs access to GitHub, the supported manga sites and their image servers to read series, download covers and save your library, and to your library website so it can fill in series from links. Your browser hasn't granted that yet.

How do I make the repo and token?
  1. On GitHub, create a new private repository, for example manga-library-data. Tick “Add a README”.
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → pick the data repo.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token, and paste it above. Use the same token on the library website.
